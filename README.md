# 💃 Maya Dance Challenge ✨

A cute, clean, and beginner-friendly web dance game built with **pure HTML5, CSS3, and JavaScript**.

---

## 🌟 How to Play Locally

You can launch and play the game right away without installing any dependencies:

1. **Option A (Instant Play - Double Click)**:
   - Double-click `index.html` in your file explorer, or right-click `index.html` and choose **Open with > Chrome / Edge / Firefox / Safari**.

2. **Option B (Local Web Server)**:
   - If you prefer running a local server:
     ```bash
     # Using Python:
     python -m http.server 8000
     # Then open http://localhost:8000 in your browser
     ```
     or
     ```bash
     # Using npx serve:
     npx serve .
     ```

## 🎮 Game Controls

| Move | Keyboard Keys | On-Screen Dance Pad |
| :--- | :--- | :--- |
| **Left Step** ⬅️ | `←` (Left Arrow) or `A` | Tap / Click **LEFT** |
| **Jump High** ⬆️ | `↑` (Up Arrow) or `W` | Tap / Click **JUMP** |
| **Shimmy Down** ⬇️ | `↓` (Down Arrow) or `S` | Tap / Click **SHIMMY** |
| **Right Step** ➡️ | `→` (Right Arrow) or `D` | Tap / Click **RIGHT** |
| **Star Twirl** 🌀 | `Spacebar` or `Enter` | Tap / Click **TWIRL** |

*Note: Fully touch-screen and mobile friendly! You can tap the dance buttons directly on touch devices.*

## 🏆 Dance Challenges

1. **Full Show (Championship)**: Play all 4 dance challenges in sequence!
2. **1. Warm-Up Groove**: Single step prompts at a gentle tempo to learn the moves.
3. **2. Memory Dance**: Watch Maya perform a routine, then repeat her dance steps!
4. **3. Rhythm Rush**: Catch incoming rhythm beats as they hit the target circle.
5. **4. Grand Finale**: High-energy choreography mashup with twirl bonuses!

---

## ✨ Features

- **Animated Maya Character**: Fully customized SVG character with animated eyes, hair buns, and dynamic dance poses (sways, jumps, squats, twirls, celebratory victory animations).
- **In-Browser Web Audio Synthesizer**: Zero external audio files required! Generates cheerful pop music, percussion, basslines, hit chimes, and victory fanfares directly using the Web Audio API with zero CORS issues.
- **Scoring & Combo System**: Earn points for *PERFECT*, *GREAT*, and *NICE* timing with combo multipliers.
- **Star Rating & Final Results**: Detailed post-game performance card with stars (⭐ to ⭐⭐⭐), accuracy score, max combo, and celebratory confetti effects!
- **Sound & Music Toggles**: Easily toggle background music and sound effects on or off.
